# Sridhar R | Personal Portfolio

A responsive, animated 3D-inspired portfolio for Sridhar R, B.Tech Artificial Intelligence & Data Science student at Shreenivasa Engineering College.

## Live website
https://sridhar-portfolio-sridhar0709.vercel.app

## Features
- Dark, futuristic visual design with animated orbital AI core
- Responsive mobile and desktop layouts
- About, education, skills, selected projects, and contact sections
- Links to GitHub repositories, LinkedIn, LeetCode, and the INTELLENZA event site
- Public resume page with a print / Save as PDF option; phone number and street-level address are intentionally omitted
- Dedicated case-study pages for SmartBus AI, Sales Data Analysis, Neonatal Monitoring Prototype, and INTELLENZA 2K26
- Reduced-motion support for accessibility
- Static HTML, CSS, and JavaScript; no build step required

## Deploy
This repository is connected to Vercel. Commits to the production branch trigger deployments automatically.
