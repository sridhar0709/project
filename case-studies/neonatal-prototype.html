Project case study

Neonatal Monitoring Prototype

An educational software-first monitoring prototype.

The repository explores a workflow using simulated sensor readings, rule-based safety checks, anomaly detection and a Streamlit dashboard.

Open source repository ↗

Technology

PythonStreamlitSimulated sensor dataAnomaly detectionVirtual actuators

Scope / current work

  • Simulated readings support safe software development and demonstrations.
  • Rule-based alert logic and anomaly-oriented analysis.
  • Dashboard and CSV logging workflow.

Important limitations

  • This is not a clinically validated medical device.
  • Simulated values are not real patient measurements and must not guide medical decisions.
  • Hardware integration requires independent testing and appropriate clinical, electrical and safety review.
  • Next step: document test cases, sensor calibration assumptions and failure modes before any real-world evaluation.

Safety note: this page describes an educational prototype only.
