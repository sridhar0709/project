Project case study

SmartBus AI

A connected college fleet dashboard concept.

SmartBus AI explores a campus transportation workflow combining fleet visibility, student attendance operations and parent communication. It is a dashboard/prototype project, not a fully operational live-tracking service.

Open source repository ↗

Technology

Next.jsReactTypeScriptTailwind CSSSupabaseVercel

Scope / current work

  • Dashboard UI and fleet-marker concepts for a college bus workflow.
  • Repository documents the project setup and current interface.
  • Designed integration points for real GPS, RFID attendance and parent notifications.

Limitations and next steps

  • Live GPS ingestion is not confirmed as implemented.
  • Production authentication and row-level security require completion and testing.
  • Parent SMS/WhatsApp delivery remains a planned integration.
  • Next step: connect a verified GPS/RFID data source, test the end-to-end flow, and document operational evidence.

This case study avoids unverified performance claims. See the repository for the latest implementation status.
